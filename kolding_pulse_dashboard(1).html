01 · DAILY RHYTHM

When does Axeltorv come alive?

Weekdays build to a single afternoon office-hours peak. Weekends start slower, crest earlier, and carry a faint late-night tail.

Read it like this: the weekday line climbs steadily to ~16:00 (commute + lunch + after-work), while the weekend curve peaks around midday and fades earlier — a leisure rhythm, not a working one.
02 · THE CALENDAR

Thirteen weeks at a glance

Each cell is one day's total arrivals. The deep-blue February block is winter break plus back-to-back event weekends — the clear high-water mark of the period.

The story: activity is front-loaded. February's holiday-and-event cluster dwarfs the calmer spring weeks — useful when planning when the square can absorb a big crowd versus when it needs a draw.
03 · EVENT SIGNATURES

Every event has a fingerprint

Plotting an event day's hourly arrivals reveals its shape. Valentine's towers over everything; a run pulls a small, flat early crowd; a school event barely registers on the square itself.

Why it matters: two events can draw similar totals but at different hours. The Valentine's spike is concentrated 11:00–14:00 — that's the window a vendor or pop-up would actually want to be open.

05 · WEATHER

Did the weather move the crowd?

Less than you'd expect — and not the way you'd guess. Over this window, footfall ran opposite to temperature, because the coldest days carried the biggest events.

Each dot is a day. The downward drift is the February cold-but-busy effect — a reminder that correlation here is hostage to what was on, not the climate itself.
